# 📸 Postgram
A full-stack social media web application built with Node.js, 
Express, and MySQL.
## 🚀 Features
- 👤 User registration & login with bcrypt password encryption
- 📝 Create posts with image upload
- ❤️ Like posts with real-time like count update
- 💬 Comment on posts
- 🙍 Edit personal profile & profile picture
- 🔐 Admin dashboard to manage users, posts & comments
## 🛠️ Tech Stack
| Category | Technology |
|---|---|
| Backend | Node.js, Express |
| Frontend | EJS, CSS |
| Database | MySQL |
| Auth | bcrypt, express-session |
| File Upload | Multer |

## ⚙️ How to Run Locally
1. Clone the repository
2. Install dependencies: `npm install`
3. Set up MySQL database using `Untitled.sql`
4. Run the server: `node server.js`
5. Open `http://localhost:3000`
